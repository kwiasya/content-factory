# Format: Tech explainer

- id: `tech-explainer`
- Platform: YouTube long first; Shorts cut from it for the second audience
- Length: 11–20 min (the niche's outliers, `docs/research/niche-claude-code-tools.md`); never padded for length
- Source: script first: screencast of a real repo or tool, talking head in a few beats, inserts of files and pages
- Script: markdown beats with VO, SCREEN, OVERLAY and a check line per beat (`videos/<slug>/script.md`); no JSON schema yet
- Face and voice: voice throughout; face in the beats that carry trust (proof, cost, origin, ending)
- Structure: promise in the first sentence, proof inside the first minute, install or setup on screen with the command readable, one live run as the payoff, no recap, one hand-off
- Pacing: meaningful change per unit time comes from the screen changing, not from cuts (Matt Pocock: 0.17 cuts/min over 17 min)
- Packaging: title = named object + outcome, number tied to a visible object; thumbnail carries the other half; three different packages, Test & Compare
- Hook library: `formats/tech-explainer/hook-library.md` (generated; empty until hooks are saved)
- Research rules that apply: 07 (retention), 08 (first 30 s), 09 (structure), 12 (packaging), 14 (reading the curve after publishing)
- Reference Watchlist: `claude-code-tools`
- First Video: `videos/autopilot-jobsearch-long/`
