# 14 · Notes: short-form analytics (item 3) and programmatic access (item 4)

Researcher share: items 3 and 4 of `prompts/14-analytics-and-iteration.md`. Checked 2026-10-12.

**Method.** Each fact below was read in the platform's own page: raw HTML pulled with curl and stripped, or rendered in a browser for the JavaScript-only pages (TikTok API for Business, Meta developer docs, Instagram Help). Only 2 web searches ran before the shared search budget ran out, so the pages come from the docs' own navigation and known doc URLs, not from search results (see Gaps).

**Tags.** These items are mostly specification facts: what an endpoint returns, its limits and its access rules. Such a fact is neither a measurement over a sample nor an opinion, so it is tagged **DOC**, meaning a tier 1 platform documentation statement that I checked against the page text. The three CONTEXT tags are used where they apply:
- **DATA**: a platform states a measurement over a sample.
- **PRACTITIONER**: a third-party tool's own documentation of its own behaviour.
- **THEORY**: my inference from the docs, not yet tested on a live account.

**Dates.** "Doc date" is the page's own "Last updated" or "Updated" stamp. "n/s" means the page shows no stamp.

**Examples.** The prompt asks for example videos only for creative rules. Items 3 and 4 are metric and API facts, so there are no video examples here. Where a timestamp-level fact matters (retention points per second), the field definition stands in for an example.

**Negative and contested (3a)**
- Definitions conflict. Studio Help defines an engaged view as staying "past the initial seconds" (3.3). The API metric reference defines `engagedViews` as "viewed past the first frame, or the user clicks/taps to play" ([metrics](https://developers.google.com/youtube/analytics/metrics), updated 2026-09-14). These are not the same threshold, and I found no source that reconciles them.
- The two Google docs differ on the effective date. The Data API says the view-count change applies "Starting August 24, 2026" ([videos resource](https://developers.google.com/youtube/v3/docs/videos), 2026-10-08). The API revision history logs it under Aug 27 2026 as "will align". Treat views around late Aug 2026 as discontinuous.
- The ChatGPT run (`../chatgpt.md`, Table A) gives a "~75–80% view-rate" benchmark for "Viewed vs Swiped" and cites only "Shorts guide". No tier 1–3 source was found for that range. Drop it unless sourced.
