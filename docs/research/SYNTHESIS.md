# Сводка ресерча и план v1

Дата: 2026-10-10. Источники: шесть ответов deep research (`01`–`06/result-a.md`) и их проверки по локальному стабу Resolve 21.1.1 (`*/verification.md`). Второй инструмент не запускался, по решению пользователя.

## 1. Что ресерч закрыл

Это решения, по которым все шесть ответов либо согласны, либо расхождение снято проверкой по стабу.

### Resolve: свой тонкий драйвер, таймлайн пересобирается целиком

- Агент управляет Resolve Studio 21.1.1 через официальный Python API из `.venv` (Python 3.12 работает, миф про `imp` опровергнут).
- Пишем свой `resolve_driver.py` поверх типизированного стаба `DaVinciResolveScript.pyi`. Стаб кладётся агенту в контекст, разрешены только методы из него.
- Таймлайн **не редактируется на месте** (API не умеет trim/move/slip). Он строится за один проход из JSON-плана через `AppendToTimeline` с `recordFrame` и `trackIndex`, при любом изменении удаляется и собирается заново.
- После каждой записи read-back. Булевы возвраты не доказательство.
- Один процесс-клиент, таймаут на каждый вызов, Resolve открыт с проектом.
- MCP samuelgursky: только как справочник и отладка, не продакшн-путь. Встроенный MCP Blackmagic: попробовать, не строить на нём.
- Доступно в 21.1 и подтверждено стабом: переходы (`AddTransition`), фейды, скорость, нормализация громкости, громкость и панорама клипа через `SetProperty`, маркеры, LUT/CDL/DRX, теги цвета при рендере, пресеты проекта и рендера.
- Недоступно: trim/move, кривые скорости, EQ и компрессор, Resolve FX на клипе, чтение грейда, IntelliScript, AI Music Editor, Beat Detector. Async-методы 21.1.1, о которых пишут ресерчи 01 и 02, в стабе отсутствуют: считаем, что их нет.

### Оверлеи: Remotion рендерит, Resolve кладёт на V2/V3

- Анимированный текст (хук, название места, факт) рендерится в Remotion как короткий ProRes 4444 с альфой, 1080×1920, fps таймлайна, без фона и без футажа внутри. Агент импортирует и кладёт на V2/V3 по кадрам.
- Remotion бесплатен для одного человека, ставится через официальные Agent Skills, не через MCP (тот закрыт).
- Запасной путь: HyperFrames (тот же контракт: MOV с альфой) или свои Fusion Text+ шаблоны для титров, которые хочется править вживую в Resolve.
- Переходы, фейды, скорость делаются нативно через API 21.1. Whip pan и zoom punch: пререндер или руками.
- Safe zone для 1080×1920: верх 269 px, низ 672 px, бока 130 px (не 65 px по Meta: на телефоне 19.5:9 Instagram растягивает 9:16 по высоте и срезает ~98 px с каждого бока, + 32 px запаса; пост «Офис — нишевые слова для парня», 2026-10-19), плюс правая колонка 230 px ниже y≈1150. Это правило Style profile.
- Style profile хранится как `style.json` в git: шрифты, цвета, safe zone, пресеты анимаций, карта переходов. Remotion и Resolve-скрипты читают один файл.

### Цвет: один color-managed проект, тег на клип, SDR на выходе

- Проект: `colorScienceMode=davinciYRGBColorManagedv2`, таймлайн DaVinci WG / Intermediate, выход Rec.709 Gamma 2.4, тег гаммы при рендере Rec.709-A (NCLC 1-1-1).
- Каждому клипу `Input Color Space` ставится скриптом по метаданным из ffprobe + exiftool. Ровно один входной трансформ на клип, никаких CST поверх RCM.
- Детект: iPhone HDR надёжно (`arib-std-b67` + DOVI profile 8), iPhone SDR надёжно, Osmo Pocket 4 по тегу `ColorGammaSxS`. **Osmo Pocket 3 D-Log M из файла не определяется**: нужна конвенция (папка или суффикс `_DLM`) либо явный флаг. На Osmo лучше снимать HLG, не D-Log M.
- D-Log M: единственный случай с LUT. Официальный DJI LUT на ноде 1 (или свойство клипа `Input LUT`, проверить). Никогда не использовать пресет `DJI D-Log`, это другая кривая.
- Look строится **один раз руками** в Resolve (Film Look Creator, зерно, халяция), сохраняется как `looks/travel_v1.drx` в репо, агент только применяет через `ApplyGradeFromDRX`.
- Экспорт: H.264 или H.265 8-bit 4:2:0, 1080×1920, 30 fps, 20–25 Mbps, AAC 48 kHz. Перед загрузкой агент проверяет ffprobe: `bt709/bt709/bt709`, `yuv420p`, без DOVI.
- HDR не отдаём: микс источников, нет HDR-референса, тонмап Instagram неконтролируем.

### Глаза агента: два уровня, JSON shot-log на клип

- Уровень 0: прокси 540×960 SDR на клип (тонмап или LUT), без звука, через videotoolbox, последовательно.
- Уровень 1, локально и бесплатно: ffmpeg `signalstats` (экспозиция), `blurdetect` (резкость), `scdet` (резкие смены), OpenCV optical flow (тряска, направление, темп), Apple Vision aesthetics через маленький Swift CLI, YOLO nano для людей в кадре. Всё на прокси, по секундам.
- Уровень 2, облако: Gemini Flash-класса через Files API описывает клип, предлагает лучшие моменты и идеи оверлеев. Около $0.4–0.6 за прогулку из 60 клипов. Claude видео не принимает, ему только contact sheets отобранных моментов.
- Главный агент кадры не смотрит. Скрипт пишет JSON, агент рассуждает над JSON.
- Результат: `shotlog/<clip>.json` по схеме из ресерча 04 (per-second метрики, события, сегменты-кандидаты с оценками, описание от LLM). Кандидаты зеркалятся в маркеры Resolve.
- Не делаем: локальные видео-LLM (отвергнуты на прежнем MacBook Air M2 8 ГБ; на MacBook Pro M5 Max 36 ГБ не перепроверялись), TransNetV2, Lighthouse, Gyroflow для Osmo Pocket (гиро не экспортируется).

### Музыка и звук: трек выбирается в монтаже, нарезка по даунбитам

- По умолчанию музыка выбирается в монтаже из лицензионной библиотеки. Epidemic Sound: подписка, официальный MCP (поиск, перекрой под длину, скачивание, стемы). Альтернатива с API: ElevenLabs Music. Suno и Udio не трогаем.
- Трендовые звуки Instagram: только ручной Flow 2 (агент режет под BPM-сетку, экспорт без музыки, звук добавляется в приложении).
- Бит: Beat This! (биты и даунбиты) + librosa (энергия) + all-in-one-infer (секции). Сетка нарезки по энергии: интро каждые 2 такта, середина каждый такт, дроп каждые 2 бита. Склейка на 1–2 кадра раньше удара.
- Живой звук прогулки остаётся подложкой: ffmpeg `highpass=100`, лёгкий `afftdn`, фейды 30 мс на стыках. Уровень −18…−24 dB под музыкой: ставится через `AudioVolume` в Resolve (стаб это подтверждает, ресерч 05 ошибся). Речевые шумодавы на эмбиенс не применять.
- Мастеринг: −14 LUFS / −1 dBTP (`NormalizeAudioLevel` или ffmpeg `loudnorm` двухпроходный), AAC 256–320 kbps.

### Script: шаблон и правила

- Поля Script: concept, target_length (45–60 с), hook {type, text ≤8 слов, shot}, shots[] {clip, in, out, role, overlay_text, overlay_type, transition, beat_index}, ending (loop_match по умолчанию), cta на отправку, caption (первая строка с названием места), hashtags ≤5, location_tag, alt_text, music brief.
- Правила: хук в секунде 0–1; один оверлей на сцену, держится ≥2 с; порядок клипов **не хронологический**, промпт явно разрешает переставлять; текст пишется под просмотр без звука; только свой футаж.
- Паттерн генерации: storyboard card на клип (это и есть shot-log) → планировщик → 3–5 вариантов хука → критик → Python-валидатор (длина, слова, safe zone, in/out внутри клипа, ≤5 хештегов).
- Данные под будущие метрики (watch time, shares) в Script оставляем сразу, публикацию через API в v1 не делаем.

## 3. Smoke-тесты до любого кода пайплайна

Каждый тест: скрипт в `tests/smoke/`, запускается при открытом Resolve, результат пишется в `docs/research/smoke-results.md`. Без них план остаётся теорией.

| # | Что проверяем | Почему |
|---|---|---|
| S1 | Подключение из `.venv`, `GetVersionString`, `GetProductName` | База |
| S2 | Создать проект, выставить ключи RCM, прочитать обратно все `GetSetting()`, зафиксировать точные строки для DWG/Intermediate | Ресерч 03 не знает точных строк |
| S3 | Таймлайн 1080×1920 30 fps, `AppendToTimeline` с `recordFrame` и `trackIndex` на V1 и V2, read-back позиций | Основа сборки и оверлеев |

| S5 | `InsertFusionTitleIntoTimeline("Text+")`: на какой трек и куда встаёт, ripple или нет, `SetInput("StyledText")`, рендер кадра | Главное расхождение ресерчей 01 и 02 |
| S6 | `SetClipProperty('Input Color Space', …)` с кандидатами строк (`Rec.2100 HLG (Scene)`, `Apple Log`, `Rec.709 Gamma 2.4`), `Input Gamma` отдельно при `separateColorSpaceAndGamma=1`, `Input LUT` как свойство клипа | Ресерч 03 считает гамму нераздельной, стаб говорит иначе |

## 5. Фазы v1

Каждая фаза заканчивается артефактом в репо и скиллом в `.claude/skills/`, которым агент эту фазу выполняет.

| Фаза | Вход → выход | Скилл |
|---|---|---|
| 0. Окружение | smoke-тесты S1–S10, по одному файлу с каждого устройства → `docs/research/smoke-results.md`, таблица детекта цвета как данные | — |
| 1. Ingest | `~/Movies/content-factory/<footage-id>/raw/` → `clip_manifest.json` (устройство, fps, VFR, цветовой профиль с confidence, время), прокси 540p | `ingest-footage` |
| 2. Shot-log | прокси → `shotlog/<clip>.json` (только локальные метрики) | `analyze-clips` |
| 3. Script | shot-logs + `style.json` + music brief → `reels/<reel>/script.json`, валидатор | `write-script` |
| 4. Бит | трек от пользователя (файл) → `beats.json` → `cuts.json` по сетке энергии | `beat-grid` |
| 5. Сборка | script + cuts + style → Remotion-оверлеи → проект Resolve: таймлайн, теги цвета, LUT для D-Log M, look DRX, уровни звука, маркеры | `build-reel` |
| 6. Рендер и проверка | рендер 1080×1920 → ffprobe-проверка тегов, LUFS → ты правишь в Resolve → повторный рендер | `render-reel` |

Порядок реализации: 0 → 1 → 5 (с ручным script.json, без оверлеев) → 6. Это даёт первый Reel из Resolve раньше всего. Потом 3 → 2 → 4, затем оверлеи в 5.

## 7. Риски

1. **Дрейф API и молчаливые частичные записи.** Read-back везде, smoke-тесты после каждого обновления Resolve, версия Resolve зафиксирована.
2. **Память и нагрузка.** Ограничения ниже заданы под прежний MacBook Air M2 8 ГБ; сейчас фабрика работает на MacBook Pro M5 Max, 36 ГБ, и они пока действуют, но не перемерены: прокси вместо 4K HEVC для анализа (они же быстрее и дешевле для метрик), анализ последовательно, Remotion при простаивающем Resolve с concurrency 2, без Magic Mask и тяжёлого Fusion в автоматическом пути. Ослаблять их по замерам на новой машине.
3. **Цвет ломается невидимо для API.** Детерминированная таблица метаданные → тег, SDR-выход, кадры-стопы на проверку глазами.
4. **D-Log M не детектится.** Конвенция папки, иначе снимать HLG.
5. **«Вкус» при выборе моментов не решён.** Ожидать правки трети выборов, логировать правки как few-shot примеры.
6. **Цены и условия облачных сервисов плывут.** Проверять при подключении, не хардкодить.

## 8. Кандидаты в ADR

Предлагаются к записи после утверждения плана, каждый трудно обратим и удивит читателя без контекста:

- **Таймлайн пересобирается из плана, никогда не правится на месте через API.**
- **Оверлеи рендерятся вне Resolve (Remotion, ProRes 4444 alpha)**, если S5 и S9 это подтвердят.
- **Отдаём SDR Rec.709, не HDR**, несмотря на HDR-источники и поддержку HDR в Instagram.
- **Главный агент не смотрит кадры, только JSON shot-log.**
