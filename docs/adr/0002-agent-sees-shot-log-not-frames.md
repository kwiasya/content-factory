# Editor «видит» клипы только через Shot log, а не через кадры

Главный агент никогда не получает кадры видео в контекст. Отдельные скрипты считают по 540p-прокси локальные метрики (экспозиция, резкость, тряска, направление движения, люди в кадре, эстетика через Apple Vision) и пишут один JSON Shot log на Clip; агент рассуждает над этими JSON и при необходимости смотрит несколько контактных листов отобранных моментов. Причины: 1200 кадров одной прогулки это около двух миллионов токенов и не помещаются в сессию; локальные метрики бесплатны и работают на M2 с 8 ГБ; облачные видео-модели по решению пользователя (2026-10-10) не используются, но могут быть добавлены как второй уровень поверх той же схемы без изменения остального.

## Consequences

- Качество выбора «лучшего момента» ограничено метриками без семантики. Ожидаем ручные правки; их логируем как примеры для будущей калибровки.
- Схема Shot log (`reel-shotlog/1.0`, см. `docs/research/04-video-understanding-shot-quality/result-a.md`, секция C) становится контрактом между анализом и Script.
