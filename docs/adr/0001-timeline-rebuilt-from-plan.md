# Таймлайн в Resolve пересобирается из плана, а не правится на месте

Scripting API Resolve Studio 21.1 не умеет двигать, подрезать или переставлять уже положенный на таймлайн клип: есть только геттеры, а «удалить и положить заново» теряет грейд и маркеры. Поэтому Editor держит единственный источник истины в JSON-плане (`script.json` + `cuts.json`), строит таймлайн из него за один проход через `AppendToTimeline` с явными `recordFrame` и `trackIndex`, и при любом изменении удаляет таймлайн и собирает заново. Ручные правки пользователя в Resolve живут в его копии таймлайна и в план не возвращаются; это цена за то, что сборка детерминирована и воспроизводима.

## Considered options

- Правка на месте через API: невозможна.
- UI-автоматизация (pyautogui, AppleScript): хрупко и мешает работе пользователя в Resolve.
- Генерация FCPXML/OTIO и импорт: подходит только для структуры нарезки, переходы и скорость адаптеры не переносят. Оставлено как запасной путь.
