# Исследовательский контур строится на своих данных, а не на Sandcastles

Sandcastles (watchlist → outlier score → deep analysis → идеи и сценарии, MCP для Claude) делает ровно то, что нам нужно, и стоит от 49 $ в месяц с кредитами на каждый разбор. Мы его не подключаем и воспроизводим тот же контур сами: статистика и история каналов из YouTube Data API, видео и кривая most replayed через yt-dlp, транскрипт локально через stable-ts, структурный разбор скачанного Reference через наш же Shot log, всё в одной SQLite-базе вне репо. Причины: Sandcastles не покрывает длинные видео YouTube и удержание, не скачивает видео, не хранит динамику просмотров по дням и не видит свой канал через Analytics API; у нас первый новый Format это именно лонг, а «как удерживать» нужно мерить, а не угадывать. Их модель сущностей и поля deep analysis берём как есть (`docs/research/sandcastles-map.md`), чтобы не изобретать схему.

## Consequences

- Квота Data API: общий бакет 10 000 единиц в сутки (чтение статистики 1 единица на 50 видео) и с 2026-06-01 отдельный бакет на 100 вызовов `search.list` в сутки. Снимки дешёвые, поиск ограничен числом вызовов.
- Скачивание чужих видео через yt-dlp это серая зона условий YouTube; файлы живут только в `~/Movies/content-factory/references/`, в репо не попадают. (Путь в этом пункте заменён ADR 0013: `references/` лежит в общем корне.)
- Нет похожих каналов из коробки: Data API больше не отдаёт related channels, поиск новых Reference channel идёт через текстовый поиск и featured channels.
