# Desk

Desk is the Author's window over the files the Editor works with (ADR 0005, `GLOSSARY.md`: Desk). It reads and writes the same files in the repo; it has no database of its own except the `note` table in `factory.db`, launches nothing and never commits. Code: `src/cf/desk/` (API), `web/` (frontend).

## Start

```sh
uv pip install --python .venv/bin/python -e '.[desk]'   # once: fastapi, uvicorn, httpx2
npm --prefix web install                 # once
npm --prefix web run build               # after every frontend change
.venv/bin/python -m cf.desk              # http://127.0.0.1:8765/
```

`python -m cf.desk` works without the frontend built: the API answers under `/api/` and `/` shows a page that says to run the build.

## Flags

| Flag | Default | Meaning |
|---|---|---|
| `--repo PATH` | current directory | Checkout to serve. The header shows its path and branch, so a worktree is never mistaken for the main checkout. |
| `--host HOST` | `127.0.0.1` | Bind address. Anything other than `127.0.0.1`, `localhost` or `::1` needs `--token`. |
| `--port PORT` | `8765` | Port. |
| `--token T` | none | Shared token. When set, every request must carry it. |

Footage root and `factory.db` follow `cf.research`: `CF_FOOTAGE_ROOT` (default `~/Movies/content-factory`) and `CF_FACTORY_DB` (default `<footage root>/factory.db`). Desk reports them in `/api/meta` and opens the database for Notes and the research contour, one connection per request (`src/cf/desk/storeuse.py`). Reads open it read-only and never create, migrate or seed it: with no `factory.db` the Notes list is empty and every contour read is 404 naming the path; a database at another schema version is 409 until a `python -m cf.research` command migrates it. Writes (a Note, an Idea move or note, a taxonomy verdict) create and migrate it when needed but never load the taxonomy seed.

## Security

- By default Desk listens on localhost only and needs no login.
- To open it from a phone on the home network, start it with `--host 0.0.0.0 --token <random>` and open `http://<mac>.local:8765/?token=<random>` once; the browser keeps the token in an HttpOnly cookie. API clients send `Authorization: Bearer <random>`. Requests without the token get 401.
- Traffic is plain HTTP. Run it on a trusted network only, never on a public one and never behind a port forward.
- Desk reads and writes only paths from its catalogue (below); any other path, `..` traversal or a symlink out of the repo is 404.

## Catalogue

The groups live in one place, `GROUPS` in `src/cf/desk/catalog.py`; a new group is one more entry (id, title, globs, editable flag, title rule, empty-state hint). Kind is `json` for `.json`, otherwise `markdown`.

| Group | Files | Editable |
|---|---|---|
| `skills` | `.md` and `.json` under `.claude/skills/*/` except `remotion-*` | yes |
| `skills-vendored` | `.md` and `.json` under `.claude/skills/remotion-*/`, hidden unless `?all=1` | no |
| `content` | `CLAUDE.md`, `docs/agents/*.md`, `style.json`, `research/templates/*.md`, `research/taxonomy.json`, `author/*.md` (empty state "run /author-setup" when `author/` is missing) | yes |
| `formats` | `formats/*/FORMAT.md` editable, `formats/*/hook-library.md` read-only (generated by `hooks export`) | partly |
| `research` | `docs/research/SYNTHESIS*.md` and `NN-*/rules.md` editable; `docs/research/README.md`, the answers `NN-*/*.md` (`chatgpt.md`, `result-a.md`, `verification.md`) and `NN-*/notes/*.md` read-only; `docs/research/prompts/` is not catalogued at all | partly |

## API

| Endpoint | Returns |
|---|---|
| `GET /api/meta` | `repo`, `branch`, `footage_root`, `db_path` |
| `GET /api/catalog[?all=1]` | groups with `docs` (`path`, `title`, `kind`, `editable`, `git`; skill files also `description` from the SKILL.md frontmatter, null for other files, `size` and `mtime`, shown in the sidebar tooltip and on the skill page) and `empty` hints |
| `GET /api/doc?path=` | the entry plus `text` and `hash` (`sha256:<hex>` of the bytes on disk) |
| `PUT /api/doc` | body `{path, text, hash}`: writes atomically (temp file + rename) when `hash` matches the file; 409 with the fresh `text` and `hash` when the file changed since it was read; 403 for read-only; 422 for invalid JSON in a `json` document |
| `GET /api/doc/diff?path=` | `git` state and unified `diff` against HEAD (untracked and ignored files diff against empty) |
| `GET /api/doc/log?path=` | commits touching the file: `hash`, `date`, `author`, `subject` |
| `GET /api/formats` | `formats`: one per `formats/*/FORMAT.md` (`id` = folder, `title` from the `# Format: …` heading, `path`, `has_hook_library`) |
| `GET /api/formats/{id}` | `format` (`path`, `text` of FORMAT.md; edit it through `PUT /api/doc`), `hook_library` (`path`, `text`, or null until `hooks export`), `topics` (two-digit numbers from the "Research rules that apply" line, each with its `docs/research/NN-*/rules.md` path or null), `rules` (rows of those tables: `topic`, `id`, `rule`, `scope`, `tag`, `source`, `confidence`, mapped by the table header), `videos` (the Videos list of `GET /api/videos`, legacy Reels included as format `walk-reel`, whose `format` is `id`: `slug`, `title`, `status`, `channel`, `path` of the folder) |
| `GET /api/skills/lint` | `skills`: broken reference count per own skill, for the catalogue badge |
| `GET /api/skills/{name}/lint` | `missing_paths` and `missing_skills` (`ref`, `file`, `line`) for one own skill; 404 for vendored or unknown skills |
| `GET /api/notes[?kind=&key=&all=1]` | `notes`: open Notes (all with `all=1`), oldest first, optionally of one `kind` and `key` |
| `POST /api/notes` | body `{kind, key, text}`: 201 with the Note; 422 for an unknown kind, a missing key or empty text |
| `POST /api/notes/{id}/resolve` | the Note with `resolved_at` set; 404 for an unknown id |
| `DELETE /api/notes/{id}` | the deleted Note; 404 for an unknown id |
| `GET /api/research` | `topics` from the folders `docs/research/NN-slug/` (`id`, `number`, `slug`, `title` and `status` from the README table, flags `chatgpt`, `result_a`, `rules`, `verification`, `notes` paths, `docs` paths), `synthesis` paths, `readme` path |
| `GET /api/search?q=[&all=1]` | case-insensitive substring search over every catalogued document (hidden groups only with `all=1`): `groups` of `hits` (`path`, `title`, `count` of matching lines, up to 3 `snippets` with `line` and `text`), `total`, `truncated` after 200 hits; 422 for a blank query |
| `GET /api/skills/links` | for every own skill: `paths` it mentions that exist in the repo (`catalogued` is the subset Desk can open), `commands` (`cf.research <group> [<cmd>]`), store `tables` (names from `CREATE TABLE` in `src/cf/research/store.py`, counted when written as `` `name` ``, `name table`, `name row(s)` or after `FROM`/`JOIN`/`INTO`/`UPDATE`), `skills` (folders under `.claude/skills/` written as `/name`, `` `name` `` or `.claude/skills/name`) and `mentioned_by` |
| `GET /api/skills/{name}/links` | the same entry for one own skill; 404 for a vendored or unknown one |

Skill lint reads every `.md` of the skill. A path is a token with `/` or ending in `.md`, `.json`, `.py`, without placeholders (`<>{}*$~:`) or `..`, whose first segment exists at the repo root, the skill folder or the file's folder; it is broken when it exists in none of those. A skill mention is `/name`; it is broken when `.claude/skills/<name>/` does not exist and `name` is not a Claude Code built-in command.

Git is read-only: status, diff, log. Commits stay with the Author or the Editor.

Search and the link map read the files on every request; there is no index or cache.

## Notes

A Note is the Author's remark on one entity for the Editor (`GLOSSARY.md`: Note), the only channel from Desk to the Editor (ADR 0005). Table `note` in `factory.db` (store migration V5): `id`, `kind`, `key`, `text`, `created_at`, `resolved_at` (empty while open). Code: `cf.research.notes`.

| Kind | Key |
|---|---|
| `document` | repo-relative path of a catalogued document, e.g. `.claude/skills/reel/SKILL.md` |
| `skill` | skill name, e.g. `write-script` |
| `video`, `card`, `idea` | the entity's id: the Video slug (`<walk>~<reel>` for a legacy Reel), the Reference's YouTube video id, the Idea id |
| `general` | empty: applies to every skill |

In Desk every document, Video page, Reference card and Idea has a Notes box under it (add, resolve, delete), and the Notes page (`#/notes`) lists all open Notes grouped by kind and takes general Notes. The Editor uses the CLI:

```sh
python -m cf.research notes list [--kind K] [--key PATH|ID] [--all] [--json]
python -m cf.research notes add <kind> <key> "<text>"     # "" as key for general
python -m cf.research notes resolve <id>
python -m cf.research notes delete <id>
```

### Skill hook

`.claude/settings.json` runs `.claude/hooks/skill_notes.py` (with `.venv/bin/python`) on `PreToolUse` for the `Skill` tool and on `UserPromptExpansion` (a typed `/skill` bypasses `PreToolUse`). It hands the Editor, as `additionalContext`, the open Notes of kind `skill` for that skill, of kind `document` under `.claude/skills/<skill>/`, and the `general` ones, with the command to resolve them. It reads `factory.db` read-only with the stdlib (same path rules as `cf.research`) and never migrates it; with no db, no `note` table, no matching Notes or unexpected input it prints nothing and exits 0. The rule in `CLAUDE.md` (Agent skills, Notes) covers the entity a skill works on, which the hook cannot know.

## Videos

Code: `src/cf/desk/videos_api.py`, `src/cf/desk/media.py`, `web/src/videos/`. Desk lists every `videos/<slug>/video.json` in the footage root (ADR 0006) and every legacy `<walk>/reels/<reel>/`, addressed as `<walk>~<reel>`, with format `walk-reel` and a status derived from the folder: `script` when a `script*.json` exists, `edit` with `cuts.json` or overlays, `review` with a render in `out/`. Everything is read per request; nothing is cached.

`video.json` is `cf-video/1`: `slug`, `title_working`, `format`, `channel`, `language`, `walks`, `status`, `history[{status, at, note}]`, `references`, `ideas`, `published_url`. Statuses in order: `idea`, `brief`, `script`, `recording`, `edit`, `review`, `published`.

| Endpoint | Returns |
|---|---|
| `GET /api/videos` | `videos` (`slug`, `title`, `format`, `channel`, `status`, `legacy`, `updated`, `error`), newest change first |
| `GET /api/videos/{slug}` | `video` (the `video.json`, or the derived one for a legacy Reel), its `hash`, `statuses`, `files` (`path`, `kind`, `size`, `mtime`, `editable`, `media`) and the Walk `proxies` |
| `POST /api/videos/{slug}/status` | body `{status, note, hash}`: sets the status, appends `{status, at: today (UTC), note}` to `history` and rewrites `video.json`; 409 on a stale hash or for a legacy Reel, 422 for an unknown status |
| `GET /api/videos/{slug}/file?path=` | an editable text of the folder (`script*.md|json`, `brief.md`, `notes.md`, `references.md`, `.srt`/`.vtt`): `kind`, `format`, `text`, `hash` |
| `PUT /api/videos/{slug}/file` | body `{path, text, hash}`: the same hashed atomic write as documents; `brief.md` and `notes.md` can be created with `hash: ""`; the hash is checked first (409 on a stale one, before any JSON check); a `script*.json` must be a `cf-script/1` document (a missing or other `schema` is a violation) and is validated by `cf.script_schema` (with the Walk's `clip_manifest.json` and the repo `style.json` when present); 422 with `violations` writes nothing |
| `GET /api/media?path=` | file streaming with HTTP Range (206) for paths relative to the footage root under `videos/<slug>/{renders,overlays,sources}/`, `<walk>/proxy/`, `<walk>/reels/<reel>/`, `references/<watchlist>/<id>/proxy.mp4`; `raw/`, symlinks out, directories and everything else are 404 |

The web page lives at `#/videos` (list) and `#/videos/<slug>`; a Video page links its `video.json` `references` to their cards (`#/contour/cards/<id>`) and its `ideas` to the Idea inbox (`#/contour/ideas/<id>`). ProRes 4444 overlays play in Safari only.

## Research contour

Code: `src/cf/desk/contour_api.py`, `web/src/contour/`. The research contour (`GLOSSARY.md`, section Исследование) over `factory.db`: Watchlists, their feed, Reference cards, summaries, the Idea inbox with Briefs, the taxonomy and today's quota. Every endpoint calls `cf.research` modules directly (no subprocess, nothing on the network: scout, snapshot and fetch stay with the Editor) and opens a Store per request (read-only for reads, see above). An unknown Watchlist, Reference or Idea is 404; any other error the CLI reports as a user error (`USER_ERRORS` in `cf.research.cli`, plus a bad summary name) is 422 with the message, violations appended one per line.

| Endpoint | Returns |
|---|---|
| `GET /api/contour/watchlists` | `watchlists` (`name`, `format_id`, `author_channel`, `language`, `region`, `queries`, `channel_count`, `created_at`) |
| `GET /api/contour/watchlists/{name}` | `watchlist` and its Reference `channels` |
| `GET /api/contour/watchlists/{name}/feed?days=&min_outlier=&min_views=&kind=&max_duration=&limit=` | `rows` as `feed --json` prints them (Outlier score rounded to 2 places, `analyzed` false = `без разбора`, `candidate` = `кандидат`), with the CLI defaults: 30 days, limit 20, no other filter; 422 for a kind other than `short`/`long` |
| `GET /api/contour/cards/{video_id}` | YouTube id or store id: `reference` (the feed row with its Outlier score), `card` (`schema`, `measured`, `analysis` or null), `sections` (the transcript sections of `measured`), `proposed` (category values of the analysis awaiting approval), `media` (`references/<watchlist>/<id>/proxy.mp4` for `/api/media` when the proxy exists, else null); 404 naming `fetch` when the Reference has no card |
| `GET /api/contour/watchlists/{name}/summary/{hooks\|formats\|topics}?days=` | the summary as `summary <what> --json` prints it (default 14 days, outlier threshold 2, 10 groups and uncarded rows); 422 for another name |
| `GET /api/contour/ideas?watchlist=&status=` | `ideas` (of every Watchlist when `watchlist` is empty), `statuses`; 422 for an unknown status |
| `POST /api/contour/ideas/{id}/{shortlist\|discard\|restore}` | the moved Idea; 422 when the status does not allow the move |
| `PUT /api/contour/ideas/{id}/notes` | body `{text}`: appends a note `{at, text}` to the Idea (as `ideas note`) and returns it; 422 for empty text |
| `GET /api/contour/ideas/{id}/brief` | `path` (`brief_path`), `text`, `hash`; 404 with the `ideas brief <id>` command while the Idea has no Brief, or when the file is missing or not a `.md` under the footage root by the same rule as Video texts and media (`src/cf/desk/paths.py`: no `..` or hidden part, no symlink on the way) |
| `PUT /api/contour/ideas/{id}/brief` | body `{text, hash}`: the same hashed atomic write as documents (409 with the fresh `text` and `hash` on a stale hash) |
| `GET /api/contour/taxonomy?kind=&status=` | `values` (`kind`, `value`, `status`, `source`, `label`, `note`), `kinds`, `statuses` |
| `POST /api/contour/taxonomy/{kind}/{value}/{approve\|reject}` | the value with `cards`: approve drops the `proposed:` prefix in every card that proposed it (store and `card.json` under the footage root); reject lists the cards that now fail validation |
| `GET /api/contour/quota` | `day` (Pacific), `buckets` (`bucket`, `limit`, `used`, `remaining`), `by_method`, `limits` |

Pages: `#/contour` (Watchlists and quota), `#/contour/watchlists/<name>` (channels, queries, feed with the CLI filters), `#/contour/watchlists/<name>/summary` (hooks, formats, topics tabs), `#/contour/cards/<id>` (measured facts, heatmap peaks as an SVG bar chart over the duration with the quote on hover and seek on click, transcript sections and chapters next to the proxy player, the analysis), `#/contour/ideas[/<id>]` (inbox with filters and actions, the selected Idea with notes and the Brief editor), `#/contour/taxonomy` (values by kind, the proposed ones by default, with approve and reject). Empty states name the next skill or command: `/research-watchlist`, `/scout-references` (`scout`), `/analyze-reference`, `/suggest-ideas`, `ideas brief <id>`.

## Frontend

`web/` is Vite + React + TypeScript + CodeMirror 6. Routes are hash routes: `#/doc/<path>` (document with Edit, Diff vs HEAD and History tabs; a skill's `SKILL.md` also shows what it mentions and who mentions it), `#/research` (topics with file flags, synthesis), `#/research/<NN-slug>` (`rules.md` with an editor, answers and notes in tabs with a contents list built from their headings), `#/search/<query>` (the header search box). `npm --prefix web run dev` starts Vite on its own port and proxies `/api` to `127.0.0.1:8765` (run `python -m cf.desk` alongside). `npm --prefix web run lint` runs eslint and tsc. The Format shelf (`#/formats`, `#/formats/<id>`) and the skill lint badge and list live in `web/src/formats/`. `npm --prefix web run build` writes `web/dist`, which `cf.desk` serves at `/`. `web/node_modules` and `web/dist` are gitignored.
