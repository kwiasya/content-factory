# Content Factory

Мастерская для автоматического монтажа коротких вертикальных видео: агент Claude Code собирает ролики через DaVinci Resolve Studio и внешние инструменты, человек делает финальный просмотр.

## Language

**Editor (Монтажёр)**:
Агент Claude Code, живущий в этом репо, который собирает Reel из отснятого материала, управляя Resolve Studio и внешними инструментами.
_Avoid_: бот, пайплайн, ассистент

**Reel**:
Вертикальное видео 9:16 длиной до 60 секунд, предназначенное для Instagram Reels.
_Avoid_: видос, ролик, шортс, short

**Clip**:
Один исходный короткий файл с камеры (проходка, вид, достопримечательность), уже отобранный человеком как пригодный для монтажа. Reel собирается из нескольких Clip.
_Avoid_: видосик, футаж, raw, кусок

**Walk (Прогулка)**:
Одна съёмочная сессия в одном месте: пул Clip, из которого собирается один или несколько Reel.
_Avoid_: съёмка, сессия, папка с исходниками

**Script (Сценарий)**:
Текстовый план Reel до сборки: порядок Clip, хук в первые секунды, тексты оверлеев и подпись к посту. Пишется и правится как текст, сборка идёт по нему.
_Avoid_: план, раскадровка, outline

**Style profile (Стиль)**:
Набор визуальных правил автора, общих для всех Reel: шрифты, цвета, LUT, темп нарезки, манера оверлеев.
_Avoid_: брендбук, тема, пресет

**Shot log**:
Структурированное описание одного Clip по секундам: качество кадра, движение, люди, описание содержимого и сегменты-кандидаты на попадание в Reel. Единственное, что Editor «видит» вместо самого видео.
_Avoid_: storyboard card, анализ, метрики клипа

**Look**:
Творческая цветовая обработка автора, построенная один раз руками и применяемая ко всем Reel после нормализации клипов. Часть Style profile.
_Avoid_: LUT, грейд, цветокор, пресет

**Track**:
Музыкальный файл, который автор выбирает и даёт Editor для конкретного Reel. Editor строит по нему сетку битов и режет Clip под неё.
_Avoid_: музыка, песня, звук, аудио
